I'm **Oussama Ben Slama**, a Software & AI Engineer focused on integrating AI into software applications through efficient, secure, and scalable architectures.

I enjoy working across the full AI stack, from data engineering and model fine-tuning to agentic systems and backend infrastructure.

My particular interest is in **Small Language Models (SLMs)**: building specialized, lightweight models that deliver strong performance with fewer resources.

## Featured Projects

- **[Qarai Guard – 163M](https://huggingface.co/Qarai/qarai-guard-163M-v0)**

  Published a lightweight Arabic text classifier for harmful content detection, achieving:
  - 94.72% macro F1.
  - 99.51% F1 for prompt injection detection.
  - 93.22% accuracy on unseen attack templates.

- **[Arabic Dialect-to-MSA Embeddings](https://huggingface.co/OussamaBenSlama/e5-small-dialect2MSA)**

  Fine-tuned an embedding model to retrieve Modern Standard Arabic passages directly from Arabic dialect queries, without query rewriting.

  Improved retrieval performance across five Arabic dialects, with gains of:
  - 26% for Tunisian queries.
  - 5% for MSA queries.
